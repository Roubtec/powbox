Adds `chromium` (a headless browser, for web automation and HTML to PDF or PNG), `marp` (Markdown to slide decks), `mmdc` (Mermaid diagrams to SVG, PNG or PDF) and the `playwright` CLI. Before first using one of them in a session, read its row in `/usr/local/share/agent-reference/tooling.md`, under "Contributed by the `browser` layer set".

- Playwright's browsers are not baked, and the system `chromium` does not stand in for them. The Playwright row has the one-time install and what a programmatic script needs.
